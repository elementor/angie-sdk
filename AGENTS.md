# Agent notes

## PR descriptions

Every PR description needs a `## Video proof demo` section: video proof (`.github/workflows/videoproof-ci.yml`) uses the description as its task. Write it with the angie-dev-tools `video-proof-demo` skill ([`skills/video-proof-demo/SKILL.md`](https://github.com/elementor/angie-dev-tools/blob/master/skills/video-proof-demo/SKILL.md), internal).

Install: import `elementor/angie-dev-tools` as a Cursor plugin (see its README).
